# MenuBarExecutor 界面探索

软件界面的 HTML 设计参照，也是 GitHub Pages 在线预览的发布目录。原生实现按窗口内部布局对齐；网页外部的桌面背景、审稿导航、状态选择和设计说明不属于软件界面。旧设计稿已移除。

## 打开

在仓库根目录执行：

```bash
python3 -m http.server 4311 --directory designs
```

访问 <http://localhost:4311/menu-bar-executor/>。HTML、CSS、JS 均在此目录，无外部字体、图片、脚本或构建依赖。

## 设计来源与范围

- `Sources/App/Views/InterfaceStyle.swift`：surface、chrome、subtle、material、line、text、muted、selection 配色角色及深浅色值，与 HTML 设计稿一致。
- `Sources/App/CommandPaletteView.swift`、`Views/CommandsListView.swift`、`Views/CommandEditorView.swift`、`Views/GeneralSettingsView.swift`、`Views/HistoryView.swift`：功能和字段边界。

五个评审入口覆盖命令面板、命令管理、命令编辑、通用设置、执行历史。应用内设置仍分为“命令 / 通用”两个标签；顶部五页导航、主题切换、自动执行状态选择和设计说明仅用于评审。

审稿页外部背景采用浅色中性灰 `#f4f4f4`、深色中性灰 `#171717`，浅色窗口阴影去除绿色调，使应用窗口成为主体。背景、审稿导航和设计说明均不属于软件界面。应用内保留系统蓝、系统中文字体和等宽命令文字，用列表分隔线与材质层次组织信息；未增加软件设置或数据字段。

## 尺寸与风格

以下尺寸、配色、线框和字号同步用于 HTML 设计稿与原生应用；审稿页外部背景和导航不属于应用界面。

- 命令面板默认宽度由 560px 调到 600px；列表仍最高 410px，矮视口下进一步收缩，为搜索区、底栏和上下各 20px 留白预留高度。搜索区与底栏保持原尺寸。少量内容时面板收缩，命令较多时仅列表滚动，1000px 高视口的示例数据下面板总高约 503px。
- 命令管理与通用设置默认 900 × 640px；执行历史默认 960 × 680px；编辑窗口与弹出表单宽 620px，表单最大高 740px，并受视口高度限制。窄视口仍按可用宽度收缩。
- 移除面板分组横线，分组字重由 600 调到 500；底栏操作移除常驻按钮边框，悬停与键盘焦点反馈保留。
- 弱化管理列表分隔线，移除自动执行标签边框；命令原文与历史输出从 11px 提到 12px。
- 深色表面改为中性灰，统一标题区、工具栏与底栏的深色表面；保留系统蓝与成功、失败状态色，浅色选中背景稍减饱和度。
- 自动执行结果在普通、悬停和键盘聚焦状态下均不添加文字下划线。原文中的 `_` 字符保留；有输出时仍可点击查看，悬停或聚焦时显示箭头与变色提示。

验收时在深浅色下分别检查 1280px、760px 和 390px 宽视口；搜索后面板应收缩，恢复完整列表后高度受限，滚动列表时搜索区与底栏位置不变。其他四页检查长名称、命令换行或截断、列表滚动和底栏位置；历史空结果与正常列表保持同样高度。编辑表单在矮视口内滚动，保存按钮固定。

## 已同步到原生的前轮调整

编辑表单留白、结果查看提示及主要辅助字号继续保留；本轮扩大编辑表单并移除结果下划线。

- 编辑表单将“可选”与字段名放在同一行，正文间距为 12px，标题和表单上下留白为 16px；编辑预览与弹出表单统一最大高 740px，并受视口或屏幕可用高度限制。短命令在 1280 × 1000 和 760 × 1000 下可直接查看三个执行选项；较矮视口仍使用表单滚动，底部按钮固定。
- 有输出的自动执行结果在悬停或键盘聚焦时显示右箭头与变色，并提供“查看结果”提示，不添加文字下划线；加载和无输出状态不提供查看入口。原生箭头使用 SF Symbols `chevron.right`。
- 结果浮层的关闭入口使用 × 图标与透明背景，原生使用 SF Symbols `xmark`，辅助功能名称为“关闭结果”；复制按钮使用表面色与细边框，不使用系统默认灰色按钮。两者保留悬停、键盘焦点及原有操作。
- 分组、面板键盘说明、表单提示、设置说明和历史辅助文字提升到 12px；命令原文与输出继续使用等宽字体。

验收时在深浅色下检查编辑页三个选项、表单滚动和保存按钮；用鼠标及 Tab 聚焦结果，确认查看提示出现，打开结果后历史条数不变。

## 原型边界

示例数据只保存在当前页面内存，刷新恢复。点击执行只生成示例历史，不启动任何进程；示例中的清理等命令也不会运行。自动执行状态为预览，不生成历史。

目录选择、快捷键录制、通知权限、JSON 导入导出仅展示操作意图，不调用系统、不读取文件。输入法为示例列表。窗口外形、材质、尺寸与焦点行为为浏览器近似，不能替代 macOS 原生验收。HTML 未实现桌面窗口移动和尺寸持久化；原生版本保留这些能力。

历史只展示现有模型支持的时间、名称、执行内容、成功/失败和最多 500 字符输出，不增加耗时、退出码或运行中记录。

## 可重复验收

1. 命令面板搜索 `Docker`，只出现“启动 Docker 服务”，编号为 ⌘1。搜索 `compose` 或 `开发工具` 应无结果；Esc 清空，再次 Esc 关闭，点击重新打开恢复。
2. 上下键选择、回车和 ⌘1–9 模拟执行，进入历史确认新增记录。点自动执行行的结果打开浮层，选择或复制内容；Esc 或点击外部关闭浮层，历史条数不增加。
3. 切换四种自动执行状态，命令行保持 36px，加载和无输出不提供空浮层。开关深浅色后重复查看。
4. 在命令管理添加、编辑、保存命令，回面板按新名称搜索。搜索中和组首的上移按钮禁用，其他命令可在组内上移。
5. 修改编辑草稿名称、内容、目录、分组和三个开关，点删除后取消或 Esc，草稿保留。保存再打开，核对命令末尾空格及换行。只含空白的名称或内容不能保存。
6. 在通用设置切换自动检查更新、登录时启动和输入法，切换标签后值保留，刷新恢复。导入、导出、目录选择和快捷键录制应明确提示为示意。
7. 历史启用“仅失败”，只显示 DNS 失败记录；测试搜索无结果、空输出、复制输出、清空确认的取消和确认。刷新恢复示例记录。
8. 深浅色分别在 1280px、760px 宽度下打开五页，检查列表滚动、工具栏和底栏固定、长命令截断、编辑表单与输出滚动。窄浏览器中的窗口收缩用于审稿，原生最小尺寸仍需单独验证。

中文输入回归：在仓库根目录执行 `python3 -m http.server 4312`，打开 <http://localhost:4312/Tests/PrototypeInputTests.html>。三项均应 PASS，覆盖三个搜索框组词期间保留输入节点、提交中文后过滤结果。此测试模拟 DOM 组合事件，真实输入法仍按下方原生步骤验证。

原生构建和测试沿用根目录 `AGENTS.md` 的命令，派生数据必须放在 `/tmp`。外观修改采用截图验收，不为颜色或常量编写同义反复测试。`InterfaceWindowTests` 验证内容区不叠加第二条系统标题栏（内容贴住窗口顶边，55 点标题区里的关闭按钮中心距顶 27.5 点）、关闭按钮和历史重开行为，并将深浅色、正常/最小尺寸及结果悬停/键盘聚焦的原生渲染保存到系统临时目录的 `menu-bar-executor-native-reference/`；命令面板截图使用临时配置和禁用执行的协调器。根目录 README 的两张面板截图来自这组示例数据。

保存失败使用原生错误提示。编辑与删除失败时 sheet 保持打开，草稿保留；配置写盘成功后才关闭。命令管理的上移操作及通用设置写入失败也显示原生错误提示，界面保留已保存的值。HTML 不模拟文件权限错误。

## 原生布局与验收

| 界面 | 原型尺寸与关键布局 |
| --- | --- |
| 命令面板 | 默认宽 600；搜索区高 48、字号 15、左右留白 16；行高 36、列表最高 410、底栏实际高 43；窗口圆角 15、选中圆角 7 |
| 命令管理 | 默认 900 × 640；标题区 55、工具栏 64、列表约 443；编辑和上移按钮常驻 |
| 通用设置 | 默认 900 × 640；共享设置窗口；左右 30、上下 24 留白；分区圆角 11；内容区高 544 并可滚动 |
| 编辑命令 | 宽 620；独立 sheet，最大高 740 并限制到视口高度；表单滚动；分组与工作目录扣除 16 点列间距后按 1:1.4 分配宽度 |
| 执行历史 | 默认 960 × 680；标题区 55、工具栏 64、左栏默认 280、内容区约 520 |

原生仅调整首次打开的默认尺寸，保留用户保存的面板尺寸及本次运行中手动调整的设置、历史窗口尺寸；设置和历史内容最小 640 × 420，面板保留最小 360 × 250、最大 800 × 1000。默认面板在屏幕可用高度内预留上下共 40 点，用户调整过的面板仍可使用完整可用高度。搜索、选择和滚动不加动画。原生保留系统窗口按钮、文本输入、目录选择、快捷键录制、输入法列表和系统确认对话框，不复制浏览器的虚拟文件操作或审稿工具。

1. 命令面板搜索区高 48 点、字号 15 点、左右留白 16 点；输入前后及显示清空按钮时高度一致，文字居中且不裁切。设置与历史窗口的标题区贴住窗口顶边，高 55 点，不再叠加系统标题栏的空白。深浅色分别检查四个窗口、编辑 sheet 和结果浮层，对照 `index.html` 的同名界面。检查正常尺寸、最小宽度、最小高度和二者组合，确认工具栏与底栏固定，长名称和输出能正确截断或滚动。
2. 用不含副作用的临时命令验证键盘上下选择、回车、⌘1–9、鼠标高亮、清空搜索。中文组词期间回车确认候选，第二次回车才执行；方向键、Esc、Tab 先交给输入法。
3. 验证有输出的自动执行结果可查看和复制，不增加历史；无输出和加载不提供空入口。浮层 Esc 只关闭浮层。结果靠右，长结果向左使用标题之外的剩余宽度，与标题保留 12 点间隔；优先显示完整标题，结果保留开头、超出部分在右侧显示省略号。分别在 360、600、800 点宽度下检查短标题配长结果、长标题配长结果、短结果和多行结果；悬停或 Tab 聚焦有输出的结果时，显示右箭头与变色但没有文字下划线，原文中的 `_` 保留；长标题占满时，结果可能只剩状态标记，仍可点击查看。
4. 验证设置标签和编辑按钮的全部留白可点击，编辑后取消删除仍保留草稿，命令首尾空白原样保存。保存、目录选择、组内上移、历史复制和清空仍使用原功能。
5. 拖动面板搜索区、底栏及设置/历史标题区空白，确认能移动窗口；面板尺寸调整后重开与搜索均保留尺寸。

## 在线预览与发布

在线地址：<https://11ze.github.io/menu-bar-executor/>。

`.github/workflows/pages.yml` 将此目录直接交给 `actions/upload-pages-artifact`，不再复制单个 HTML。`index.html`、`style.css`、`app.js` 的相对引用在 Pages 子路径下保持有效。变更此目录或工作流后，推送到 `main` 自动发布，也可手动运行 Deploy design preview。

仓库 Settings → Pages → Build and deployment → Source 应为 GitHub Actions。发布后逐个核对在线 `index.html`、`style.css`、`app.js` 与此目录内容，并执行上面的交互验收。
