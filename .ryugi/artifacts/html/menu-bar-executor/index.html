把常用 Shell 命令放进 macOS 菜单栏

按快捷键呼出面板，输入名称或拼音，回车即执行。下方窗口可直接搜索、编辑、拖拽与试跑。

macOS 12.0+ · Apple Silicon & Intel

原生 macOS 体验，轻巧克制

纯 SwiftUI 与 AppKit 编写，不依赖外部运行环境。支持深浅色模式与窗口尺寸记忆，所有命令与配置明文保存在本地 JSON，随时备份迁移。

拼音与子序列模糊搜索

支持中文全拼、简拼、混合拼音与英文子序列匹配并高亮命中片段，只检索命令名称，不被长脚本内容干扰。

打开即查的行内自动执行

适合当前 IP、Git 分支等状态查询：面板打开时自动刷新并将结果显示在行内，悬停可展开复制，不污染执行历史。

双栏分组整理与显隐控制

支持拖拽调整分组与命令顺序、跨组移动；可按分组或单条暂时隐藏不常用命令，隐藏后自动执行随之暂停。

草稿试跑与历史一键重跑

编辑命令时无需先保存即可试跑验证输出；手动执行保留最近 100 条记录与输出结果，失败记录醒目标识并支持随时重跑。

输入法自动联动与本地 JSON 备份

可配置打开面板时自动切换英文输入法、关闭后恢复；配置保存在 ~/.config/menu-bar-executor/settings.json，支持一键导出导入。
