# MenuBarExecutor 界面规范与验收

软件界面以 Ryugi 交互原型 `.ryugi/artifacts/html/menu-bar-executor/index.html` 为设计参照。GitHub Pages 发布同一份文件，展示 main 分支发布的最新版交互原型，不保证与已发布的原生版本同步。原生实现按窗口内部布局对齐；网页外部的桌面背景、审稿导航、状态选择和设计说明不属于软件界面。旧设计稿已移除。

## 打开

在仓库根目录执行：

```bash
python3 -m http.server 4311 --directory .ryugi/artifacts/html/menu-bar-executor
```

访问 <http://localhost:4311/>。CSS、JS 内联在 `index.html` 中，无外部字体、图片、脚本或构建依赖。只修改这份原型，不维护发布副本。

## 设计来源与范围

- `Sources/App/Views/InterfaceStyle.swift`：surface、chrome、subtle、material、line、text、muted、selection 配色角色及深浅色值，与 HTML 设计稿一致。
- `Sources/App/CommandPaletteView.swift`、`Views/CommandsListView.swift`、`Views/CommandEditorView.swift`、`Views/GeneralSettingsView.swift`、`Views/HistoryView.swift`：功能和字段边界。

五个评审入口覆盖命令面板、命令管理、命令编辑、通用设置、执行历史。应用内设置仍分为“命令 / 通用”两个标签；顶部五页导航、主题切换、自动执行状态选择和设计说明仅用于评审。

审稿页外部背景采用浅色中性灰 `#f4f4f4`、深色中性灰 `#171717`，浅色窗口阴影去除绿色调，使应用窗口成为主体。背景、审稿导航和设计说明均不属于软件界面。应用内保留系统蓝、系统中文字体和等宽命令文字，用列表分隔线与材质层次组织信息；未增加软件设置或数据字段。

## 尺寸与风格

以下尺寸、配色、线框和字号同步用于 HTML 设计稿与原生应用；审稿页外部背景和导航不属于应用界面。

- 命令面板默认宽度由 560px 调到 600px；列表仍最高 410px，矮视口下进一步收缩，为搜索区、底栏和上下各 20px 留白预留高度。搜索区与底栏保持原尺寸。少量内容时面板收缩，命令较多时仅列表滚动，1000px 高视口的示例数据下面板总高约 503px。
- 命令管理与通用设置默认 900 × 640px；执行历史默认 960 × 680px；编辑窗口与弹出表单宽 620px，表单最大高 740px，并受视口高度限制。窄视口仍按可用宽度收缩。
- 移除面板分组横线，分组字重由 600 调到 500；底栏操作移除常驻按钮边框，悬停与键盘焦点反馈保留。
- 弱化管理列表分隔线，移除自动执行标签边框；命令原文与历史输出从 11px 提到 12px。
- 深色表面改为中性灰，统一标题区、工具栏与底栏的深色表面；保留系统蓝与成功、失败状态色，浅色选中背景稍减饱和度。
- 自动执行结果在普通、悬停和键盘聚焦状态下均不添加文字下划线。原文中的 `_` 字符保留；有输出时仍可点击查看，悬停或聚焦时显示箭头与变色提示。

验收时在深浅色下分别检查 1280px、760px 和 390px 宽视口；390 宽下底栏保留“选择”“执行”且不换行。搜索后面板应收缩，恢复完整列表后高度受限，滚动列表时搜索区与底栏位置不变。其他四页检查长名称、命令换行或截断、列表滚动和底栏位置；历史空结果与正常列表保持同样高度。编辑表单在矮视口内滚动，保存按钮固定。

## 已同步到原生的前轮调整

编辑表单留白、结果查看提示及主要辅助字号继续保留；本轮扩大编辑表单并移除结果下划线。

- 编辑表单将“可选”与字段名放在同一行，正文间距为 12px，标题和表单上下留白为 16px；编辑预览与弹出表单统一最大高 740px，并受视口或屏幕可用高度限制。短命令在 1280 × 1000 和 760 × 1000 下可直接查看三个执行选项；较矮视口仍使用表单滚动，底部按钮固定。
- 有输出的自动执行结果在悬停或键盘聚焦时显示右箭头与变色，并提供“查看结果”提示，不添加文字下划线；加载和无输出状态不提供查看入口。原生箭头使用 SF Symbols `chevron.right`。
- 结果浮层的关闭入口使用 × 图标与透明背景，原生使用 SF Symbols `xmark`，辅助功能名称为“关闭结果”；复制按钮使用表面色与细边框，不使用系统默认灰色按钮。两者保留悬停、键盘焦点及原有操作。
- 分组、面板键盘说明、表单提示、设置说明和历史辅助文字提升到 12px；命令原文与输出继续使用等宽字体。

验收时在深浅色下检查编辑页三个选项、表单滚动和保存按钮；用鼠标及 Tab 聚焦结果，确认查看提示出现，打开结果后历史条数不变。

## 本轮调整（已同步到原生）

2026-11-18 评审后先改设计稿，再同步到原生。下面记录改法与差别。

- 命令面板选中行文字改用 `--selected-text`：浅色 `#005ecb`，深色不变 `#83b9ff`。浅色下 13px 文字在选中底 `#e4edfa` 上的对比度由 4.29:1 提到 5.14:1；选中行里有输出的结果在悬停和聚焦时用同一颜色。搜索命中的片段也用这个颜色；未选中行的命中片段用 `selectedText`（浅色 `#0068e8`，在 `#fdfdfe` 上 5.07:1，原为系统蓝 4.02:1）。原生新增 `InterfaceStyle.selectedRowText`，`selectedText` 保持不变，仍用于焦点描边、悬停文字和未选中行的命中片段。
- 通用设置压紧行距：最小行高 63 → 52、行内上下 13 → 8、分区间距 20 → 14、内容区上下留白 24 → 18；分组标题下边距 8 → 6。设计稿另把说明文字行高 1.7 → 1.55；原生不设行高，随系统字型，两行文案实测 51–52。默认 900 × 640 下三组设置完整可见，不再被底栏切断。
- 命令管理改为左右双栏（纯分组侧栏 + 右侧命令区）：左侧 224 点宽分组栏常驻显示所有命名分组与底部固定「未分组」（无「全部命令」），支持分组拖拽排序、悬停行内重命名/删除（需二次确认，组内命令自动移入未分组、不删除命令）与底部「＋ 新建分组」；右侧展示当前选中分组命令，支持组内拖拽排序与拖至左侧分组/未分组跨组移动，顶部搜索框跨全部分组搜索（清空回到当前分组），从命名分组添加命令时预填该组，跨组搜索时默认「未分组」；命令原文与编辑按钮样式沿用现有规范，移除原单向 `↑` 按钮。删除命令与删除分组均需原生确认对话框。
- 执行历史输出框去掉 143px 最小高，改为内容高度，仍保留 260px 上限与滚动。
- 编辑表单的命令文本域从 12px 提到 13px（文本输入本来就是 13px）；设计稿另把文本域行高 1.7 → 1.6。
- 历史列表的失败记录在名称后加 12px 的“失败”文字，不再只靠圆点颜色区分。
- 面板搜索占位统一为“搜索命令名称”；“系统通知”右侧按钮由“查看说明 ↗”改为“打开系统设置 ↗”；快捷键统一写成 `⌃⌥Space`；快捷键为空时“清除”按钮禁用。原生由快捷键录制控件显示格式，不单独改文案。
- 面板窄于 600 时不再隐藏“选择”“执行”文字：540 以下键帽间距收到 4、底栏间距 6，360 宽仍完整显示，与原生 360–800 的可缩放范围一致。
- 结果按钮的键盘焦点环改为贴合控件（偏移 0、圆角 6），不再压住 ⌘N；结果仍在 Tab 链中，回车只打开结果。

原生落点：`InterfaceStyle.swift`、`CommandPaletteView.swift`、`CommandsListView.swift`、`GeneralSettingsView.swift`、`HistoryView.swift`、`CommandEditorView.swift`。与设计稿的差别：结果按钮沿用系统外焦点环，不改偏移；面板收窄时由 SwiftUI 间距自适应，360–800 全宽保留“选择”“执行”；侧栏分组悬停按钮与右侧子栏并列的“重命名分组 / 删除分组”互为补充，确保键盘与辅助功能可达。

验收：深浅色下打开通用设置，默认尺寸内三组完整可见；命令管理双栏清晰、首次打开自动聚焦首个有命令的分组，悬停任一命令行出现编辑按钮边框，指针移到按钮上变选中色底；历史选中失败记录，列表出现“失败”字样；面板选中行文字为更深的蓝；在面板搜索 `Docker`，选中行命中片段与其余文字同色；Tab 到结果按钮，焦点环不覆盖 ⌘N。

## 显隐控制（已同步到原型与原生）

- 分组（含底部「未分组」）与命令各自独立支持显隐控制：隐藏分组不会覆写组内命令各自的 `hidden` 标记；恢复显示分组后，原自身隐藏的命令保持隐藏。重命名分组同步迁移隐藏状态，删除隐藏分组时清理分组隐藏记录并保留组内命令各自的显隐标记。
- 命令管理采用行内眼睛直控：左侧正常分组悬停显现 `eye / pencil / xmark`（未分组显现 `eye`），已隐藏分组名称降淡并常驻可点击的 `eye.slash`；右侧子栏同步提供「隐藏分组 / 显示分组」操作，选中已隐藏分组时在子栏下方展示温和横幅并附「恢复显示分组」按钮；命令行悬停在「编辑」左侧显现 `eye`，已隐藏命令整行降淡、常驻 `eye.slash` 并标注「已隐藏」；开启自动执行的命令隐藏后标签切换为「自动执行 · 已暂停」或「自动执行 · 随组暂停」；底栏展示总条数、可见条数及生效中的自动执行条数。
- 命令编辑表单在选项区增加「在命令面板中隐藏」复选框；当开启自动执行且命令自身或所选分组已隐藏时，下方即时显示「自动执行暂不生效」提示。
- 命令面板及面板搜索严格过滤隐藏分组与隐藏命令，快捷键 `⌘1`–`⌘9` 在可见命令上连续重排，隐藏的自动执行命令不会运行；当所有命令均被隐藏时，面板空态提示「所有命令均已隐藏」并提供「打开设置」入口。命令管理页搜索始终包含隐藏项。

## 原型边界

示例数据只保存在当前页面内存，刷新恢复。点击执行只生成示例历史，不启动任何进程；示例中的清理等命令也不会运行。自动执行状态为预览，不生成历史。

目录选择、快捷键录制、通知权限、JSON 导入导出仅展示操作意图，不调用系统、不读取文件。输入法为示例列表。窗口外形、材质、尺寸与焦点行为为浏览器近似，不能替代 macOS 原生验收。HTML 未实现桌面窗口移动和尺寸持久化；原生版本保留这些能力。

历史只展示现有模型支持的时间、名称、执行内容、成功/失败和最多 500 字符输出，不增加耗时、退出码或运行中记录。

## 可重复验收

1. 命令面板搜索 `Docker`，只出现“启动 Docker 服务”，编号为 ⌘1。搜索 `compose` 或 `开发工具` 应无结果；Esc 清空，再次 Esc 关闭，点击重新打开恢复。
2. 上下键选择、回车和 ⌘1 至 ⌘9 模拟执行，进入历史确认新增记录。点自动执行行的结果打开浮层，选择或复制内容；Esc 或点击外部关闭浮层，历史条数不增加。
3. 切换四种自动执行状态，命令行保持 36px，加载和无输出不提供空浮层。开关深浅色后重复查看。
4. 在命令管理切换左侧分组，新建、重命名、拖拽排序与删除分组（点删除后弹出确认，取消保留原分组，确认后命令保留在「未分组」），确认命令面板顺序同步。在右侧拖拽调整组内命令顺序、将命令拖到左侧其他分组或「未分组」完成换组；点击搜索框内的文字、放大镜或留白都可输入。搜索框获得焦点时立即显示蓝色边框，移走焦点后恢复普通边框。搜索时跨全部分组显示命中项，收起底栏拖动提示，添加命令默认「未分组」。清空搜索后返回当前分组，恢复拖动提示；从命名分组添加命令时预填该组。
5. 修改编辑草稿名称、内容、目录、分组和三个开关，点删除后取消或 Esc，草稿保留。保存再打开，核对命令末尾空格及换行。只含空白的名称或内容不能保存。
6. 在通用设置切换自动检查更新、登录时启动和输入法，切换标签后值保留，刷新恢复。导入、导出、目录选择和快捷键录制应明确提示为示意。
7. 历史启用“仅失败”，只显示 DNS 失败记录；测试搜索无结果、空输出、复制输出、清空确认的取消和确认。刷新恢复示例记录。
8. 深浅色分别在 1280px、760px 宽度下打开五页，检查列表滚动、工具栏和底栏固定、长命令截断、编辑表单与输出滚动。窄浏览器中的窗口收缩用于审稿，原生最小尺寸仍需单独验证。

中文输入回归：在仓库根目录执行 `python3 -m http.server 4312`，打开 <http://localhost:4312/Tests/PrototypeInputTests.html>。三项均应 PASS，覆盖三个搜索框组词期间保留输入节点、提交中文后过滤结果。此测试模拟 DOM 组合事件，真实输入法仍按下方原生步骤验证。

原生构建和测试沿用根目录 `AGENTS.md` 的命令，派生数据必须放在 `/tmp`。外观修改采用截图验收，不为颜色或常量编写同义反复测试。`InterfaceWindowTests` 验证内容区不叠加第二条系统标题栏（内容贴住窗口顶边，55 点标题区里的关闭按钮中心距顶 27.5 点）、关闭按钮和历史重开行为，并将深浅色、正常/最小尺寸及结果悬停/键盘聚焦的原生渲染保存到系统临时目录的 `menu-bar-executor-native-reference/`；命令面板截图使用临时配置和禁用执行的协调器。

保存失败使用原生错误提示。编辑与删除失败时 sheet 保持打开，草稿保留；配置写盘成功后才关闭。命令管理的拖拽排序、分组编辑及通用设置写入失败也显示原生错误提示，界面保留已保存的值。HTML 不模拟文件权限错误。
