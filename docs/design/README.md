# 界面设计参照

直接打开 `prototype.html`，或在项目根目录执行 `python3 -m http.server 8765`，访问 `http://localhost:8765/docs/design/prototype.html`。

这是原生界面改造的 HTML 参照稿。SwiftUI 已按此稿实现命令面板、设置、命令编辑和历史布局；原生实现边界见下文。顶部导航、主题按钮和自动执行状态选择器属于设计稿查看工具，不属于软件界面。示例命令不会执行，编辑仅保存在当前页面内存中，刷新可恢复。

## 设计约定

- 按 macOS 27 方向校准：系统字体、系统蓝、紧凑列表。工具栏和搜索面板使用浅色材质层次，命令与输出保持高可读性。命令与输出使用系统等宽字体。
- 命令面板使用紧凑布局：搜索区 52px、命令行 36px、分组标题 25px、底栏约 32px；所有命令统一单行且标题左对齐，移除面板行首图标与自动执行标签。自动执行结果以状态小点和等宽文字显示在标题旁，过长时行内截断。有输出的结果不加下划线，悬停时变色，点击可在非模态浮层查看、选择和复制完整内容；点击标题才执行命令。浮层可点外部、关闭按钮或 Esc 关闭。加载和无输出状态不提供空的查看入口。面板不显示命令内容和工作目录，不提供编辑入口；查看与编辑命令统一进入设置页。未保存尺寸时，列表随内容增长，默认最高 460px；窗口宽高可手动调整并保存，搜索后保留手动高度，尺寸限制在屏幕可用区域。
- 面板底栏的历史和设置使用有底色、细边框的紧凑按钮；静止时可辨认，悬停变色，键盘聚焦使用清晰焦点环，底栏高度保持不变。
- 面板分组标题后接浅色 1px 细线，第二组起上方增加 4px 间距；命令文字相对组名缩进 8px，行高和选中背景宽度保持不变。
- 命令面板宽 560px，设置窗口宽 840px，历史窗口宽 840px；浏览器较窄时窗口随容器收缩，正式实现仍需验证原生最小尺寸。
- 命令面板与命令管理仅搜索命令标题（名称），不搜索分组或命令内容，忽略大小写。
- 搜索、选择、键盘导航均无动画；名称与结果保持固定层级。鼠标移到命令行时同步选中项，不抢搜索焦点；鼠标静止时不干扰键盘选择。
- 快捷键固定对应当前搜索结果的前 9 条命令，滚动不重新编号，第 10 条起不显示快捷键；搜索后重新编号。
- 命令管理窗口最高 620px，短视口时按可用高度收缩；工具栏、计数与底栏固定，仅中间命令列表滚动。
- 删除确认取消或按 Esc 都返回原编辑表单，保留未保存的名称、内容、目录、分组及开关。
- 自动执行的加载、成功、失败与成功无输出均保持单行 36px，可用窗口外的状态选择器预览；加载仅用静态进度标记和文字，不添加动画。
- 通用页增加默认开启的自动检查更新开关，文案为“启动时检查新版本，有更新时提醒”；状态保存在页面内存中，切换标签页保留，刷新恢复。原生版本已接入持久化配置与启动检查，关闭后仍可手动检查更新。
- 设置分为命令和通用两个标签页。命令编辑使用独立 sheet，执行结果在历史详情区查看。
- 间距使用 4/8/12/16/24px；普通控件圆角 8px，列表选择圆角 11px，窗口与 sheet 圆角 20px，工具栏搜索和分段控件为胶囊形。这些数值为 HTML 视觉近似，不是 Apple 官方精确参数；原生实现由系统控件和材质决定。

## 可重复验证

1. 鼠标依次移到不同命令上，检查高亮随鼠标移动；随后按上下键，检查键盘选择仍有效。
2. 在面板输入 `docker`，验证过滤、上下选择、回车模拟执行、Esc 清空；清空后再次 Esc 显示关闭状态。
3. 在命令面板和命令管理分别搜索 `Docker`，应显示「启动 Docker 服务」；搜索仅出现在分组的「开发工具」或仅出现在内容的 `compose`，均应无结果。搜索不存在的文字，检查无结果提示与清空入口；切换空状态后检查添加入口。
4. 在命令页编辑已有命令，保存后检查列表与面板同步；添加命令后刷新页面应恢复示例数据。
5. 打开历史，切换失败记录，检查输出、退出码、复制反馈和仅失败筛选。
6. 切换深浅色，在宽度 1280px 与 760px 下检查所有页面；检查长名称、编辑 sheet 和输出滚动。

## 尚需产品决定

- 历史中的运行状态、耗时、退出码和更长输出需要扩展当前数据模型。
- 分组顺序沿用现有配置，不新增分组排序入口；命令管理支持组内上移，搜索时禁用排序；结果与历史输出提供复制反馈。
- 超时沿用现有 30 秒，不在设计稿中增加配置选项。
- 导入导出和目录选择只展示交互意图，不访问真实文件。

## macOS 27 外观参照

- [Apple Design Resources](https://developer.apple.com/design/resources/) 提供 macOS 27 官方组件套件。
- [Adopting Liquid Glass](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass) 用于原生实现时核对材质与控件采用方式。
- HTML 使用半透明背景、轻量内高光和阴影表现层次，不模拟真实折射。主内容、编辑区和输出区保持实色。深色模式单独调整文字与表面亮度。
- 工具栏与标题栏合并为连续区域，减少横线切割；圆角仅按角色使用，不把所有列表项做成卡片。
- SVG 几何图标用于网页预览，不是 SF Symbols 导出资源；SwiftUI 实现替换为 `terminal`、`bolt`、`magnifyingglass` 等系统符号。
- 保留原生系统控件对降低透明度、增强对比度和系统强调色的支持。设计稿不能替代在 macOS 27 上的最终验收。

## 收尾验证

1. 添加到 10 条命令，检查只显示 ⌘1–9；滚动列表后仍对应原来的前 9 条，搜索后按结果重新编号。
2. 命令管理添加到 10 条以上，滚动到末尾，确认搜索框、添加按钮和底栏留在原位。
3. 编辑名称、命令、分组、目录和开关，点删除再取消，检查所有草稿保留；再次点删除后按 Esc，也应返回草稿。
4. 切换窗口外的自动执行状态预览，检查四种状态下行高一致；悬停和键盘选择时高亮同步。

## 结果查看与开关验证

- 自动执行有输出的结果可点击查看，浮层内完整文字可选择与复制；查看结果不能触发执行或新增历史。窄窗口仍维持单行 36px。
- 浮层内 Esc 只关闭浮层，保留命令面板与搜索；键盘 Tab 可聚焦结果按钮，Enter 打开浮层。
- 通用页两个开关在悬停时继续保持开启蓝色、关闭灰色，焦点环不替代状态颜色。深浅色分别验证。

## 原生实现边界与验收

- 保留 macOS 12 支持，使用系统字体、设计稿对应的深浅色角色、原生材质、按钮、sheet 与 popover；HTML 的像素数值用于布局参照，不模拟折射或自行绘制系统控件。
- 面板默认宽 560，保留已保存宽度，最小宽 360；未保存尺寸时按命令数量计算高度，列表默认最高 460；支持手动调整宽高并保存，最小高度 250、最大高度 1000，同时限制在屏幕可用区域。搜索、选择和滚动不加动画。设置默认宽 840、内容高 620，最小内容尺寸 640 × 420；历史默认 840 × 560，最小内容尺寸 640 × 420。
- 面板的 ⌘1–9 固定对应当前搜索结果前九条，滚动不重新编号；第十条起不显示快捷键。旧的可见区域编号逻辑已移除。
- 仅命令标题触发执行；有内容的自动执行结果不加下划线，悬停变色，可打开浮层选择和复制。加载、成功无输出不提供空入口。浮层打开期间面板快捷键暂停，Esc 只关闭浮层。
- 编辑 sheet 使用独立草稿，删除确认取消或 Esc 不销毁草稿。工作目录选择使用系统目录面板。
- 历史保留现有最近 100 条、每条最多 500 字符输出的存储方式；可按名称搜索、筛选失败记录、选择与复制输出。不显示缺失的运行中状态、耗时、退出码和工作目录，不把截断输出标为完整输出。
- `autoCheckUpdates` 默认 `true`；旧配置缺失字段时仍开启。关闭后跳过启动检查，延迟等待和请求完成后再次读取开关；手动检查不受影响。

原生重复验收：

1. 准备至少十条无副作用命令，覆盖分组、多行内容、长名称，以及自动执行加载、成功、失败和成功无输出。用临时配置或独立应用副本验证，避免运行日常自动执行命令。
2. 打开面板，滚动到末尾再按 ⌘1，仍执行搜索结果第一条；搜索后检查编号重排。鼠标静止时按上下键，选中项高亮应同步，不能被鼠标抢回。
3. 点击有内容的结果，选择、复制完整内容；确认历史条数不变。Tab 聚焦结果按钮，Enter 打开；Esc 关闭浮层后，面板和搜索保留。点外部关闭浮层，切换其他应用关闭面板。
4. 编辑名称、命令、目录、分组与三个开关，删除后取消及 Esc 均保留草稿；保存后重新打开核对值；取消编辑不写入配置。仅用临时命令验证实际删除。
5. 命令管理搜索仅匹配名称；组内上移不跨组，组首与搜索时按钮禁用；列表滚动时工具栏、计数、底栏保持固定。
6. 历史验证成功、失败、空输出、空记录、无匹配记录、仅失败筛选、复制反馈和清空确认取消。
7. 关闭自动检查并重启，确认不发起启动检查；手动检查仍可用。开启后验证启动检查与断网错误行为。
8. 深浅色分别检查四个界面，以及窗口最小宽、最小高、二者组合与正常尺寸。检查长输出滚动、焦点标记和屏幕边缘定位。

构建和测试沿用根目录 `AGENTS.md` 的命令，派生数据必须放 `/tmp`。HTML 的浏览器验证不能代替原生验收。

原生配色与快捷键框集中在 `Sources/App/Views/InterfaceStyle.swift`，对应设计稿的 surface、chrome、subtle、material、line、text、muted 和 selection；不把系统材质的默认灰色直接当作设计稿底色。底栏按钮沿用稿中的 24 高、6 圆角、细边框及悬停状态。

## 面板尺寸、标签命中与输入法回归

- 拖动面板下边缘改变高度；关闭、重开后尺寸保留，搜索和清空搜索不重置手动高度。窗口的最小、最大高度必须保持可调范围，不随列表内容锁成相同值。
- 设置页“命令 / 通用”标签的整个胶囊区域都可点击；分别点文字左侧、右侧和上下留白，均应切换。
- 输入法按显示名称排除含 `&` 或 `.` 的项，输入源 ID 不参与名称过滤。每次打开通用页刷新系统列表；已保存的输入源被隐藏时显示“当前配置已隐藏”，重新选择前保留原配置。
- 结果文字静止时无下划线，悬停变色；查看和复制仍不执行命令、不增加历史。

- 中文组词时，回车确认候选、方向键选词、Esc 取消组词、Tab 均由输入法先处理；确认文字后再次按回车才执行命令。原生快捷键入口也遵守此规则。
- 导入名称为空的已有命令后，编辑器仍显示“编辑命令”与删除入口；新建命令不显示删除入口。编辑模式不随草稿名称变化。

## 移除面板执行内容区

- 面板列表直接衔接快捷键、历史与设置底栏，不显示底部命令内容、工作目录或编辑按钮。查看或编辑命令从设置页进入；空列表仍保留添加入口。
- 默认高度不再预留原详情区的 65px（含分隔线），最小高度和已保存尺寸继续生效。
- 分别用普通命令、多行命令、无结果搜索和空列表验证无详情区或残留空白；鼠标与方向键选择只更新高亮。自动执行行内结果及查看、复制浮层保持可用。
