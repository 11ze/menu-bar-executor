# 界面设计参照

直接打开 `prototype.html`，或在项目根目录执行 `python3 -m http.server 8765`，访问 `http://localhost:8765/docs/design/prototype.html`。

这是待讨论的 HTML 设计稿，不是已经确定的产品规格，也不代表 SwiftUI 已实现。顶部导航、主题按钮和自动执行状态选择器属于设计稿查看工具，不属于软件界面。示例命令不会执行，编辑仅保存在当前页面内存中，刷新可恢复。

## 设计约定

- 按 macOS 27 方向校准：系统字体、系统蓝、紧凑列表。工具栏和搜索面板使用浅色材质层次，命令与输出保持高可读性。命令与输出使用系统等宽字体。
- 命令面板使用紧凑布局：搜索区 52px、命令行 36px、分组标题 25px、详情区 64px、底栏约 32px；所有命令统一单行且标题左对齐，移除面板行首图标与自动执行标签。普通命令不重复显示目录，目录随选中项显示在底部；自动执行结果以状态小点和等宽文字显示在标题旁，过长时行内截断。有输出的结果带点状下划线，点击可在非模态浮层查看、选择和复制完整内容；点击标题才执行命令。浮层可点外部、关闭按钮或 Esc 关闭。加载和无输出状态不提供空的查看入口。底部只显示实际命令、工作目录和编辑入口，不重复显示结果。列表随内容增长，最高 460px，并按视口高度收缩。
- 面板底栏的历史和设置使用有底色、细边框的紧凑按钮；静止时可辨认，悬停变色，键盘聚焦使用清晰焦点环，底栏高度保持不变。
- 面板分组标题后接浅色 1px 细线，第二组起上方增加 4px 间距；命令文字相对组名缩进 8px，行高和选中背景宽度保持不变。
- 命令面板宽 560px，设置窗口宽 840px，历史窗口宽 840px；浏览器较窄时窗口随容器收缩，正式实现仍需验证原生最小尺寸。
- 命令面板与命令管理仅搜索命令标题（名称），不搜索分组或命令内容，忽略大小写。
- 搜索、选择、键盘导航均无动画；名称与结果保持固定层级。鼠标移到命令行时同步选中项、底部执行内容与编辑目标，不抢搜索焦点；鼠标静止时不干扰键盘选择。
- 快捷键固定对应当前搜索结果的前 9 条命令，滚动不重新编号，第 10 条起不显示快捷键；搜索后重新编号。
- 命令管理窗口最高 620px，短视口时按可用高度收缩；工具栏、计数与底栏固定，仅中间命令列表滚动。
- 删除确认取消或按 Esc 都返回原编辑表单，保留未保存的名称、内容、目录、分组及开关。
- 自动执行的加载、成功、失败与成功无输出均保持单行 36px，可用窗口外的状态选择器预览；加载仅用静态进度标记和文字，不添加动画。
- 通用页增加默认开启的自动检查更新开关，文案为“启动时检查新版本，有更新时提醒”；状态保存在页面内存中，切换标签页保留，刷新恢复。此开关尚未接入原生更新逻辑。
- 设置分为命令和通用两个标签页。命令编辑使用独立 sheet，执行结果在历史详情区查看。
- 间距使用 4/8/12/16/24px；普通控件圆角 8px，列表选择圆角 11px，窗口与 sheet 圆角 20px，工具栏搜索和分段控件为胶囊形。这些数值为 HTML 视觉近似，不是 Apple 官方精确参数；原生实现由系统控件和材质决定。

## 可重复验证

1. 鼠标依次移到不同命令上，检查高亮、底部执行内容与编辑目标同步；随后按上下键，检查键盘选择仍有效。
2. 在面板输入 `docker`，验证过滤、上下选择、回车模拟执行、Esc 清空；清空后再次 Esc 显示关闭状态。
3. 在命令面板和命令管理分别搜索 `Docker`，应显示「启动 Docker 服务」；搜索仅出现在分组的「开发工具」或仅出现在内容的 `compose`，均应无结果。搜索不存在的文字，检查无结果提示与清空入口；切换空状态后检查添加入口。
4. 在命令页编辑已有命令，保存后检查列表与面板同步；添加命令后刷新页面应恢复示例数据。
5. 打开历史，切换失败记录，检查输出、退出码、复制反馈和仅失败筛选。
6. 切换深浅色，在宽度 1280px 与 760px 下检查所有页面；检查长命令、编辑 sheet 和输出滚动。

## 尚需产品决定

- 历史中的运行状态、耗时、退出码和更长输出需要扩展当前数据模型。
- 分组排序和复制反馈是待实现的交互。
- 超时沿用现有 30 秒，不在设计稿中增加配置选项。
- 导入导出和目录选择只展示交互意图，不访问真实文件。

## macOS 27 外观参照

- [Apple Design Resources](https://developer.apple.com/design/resources/) 提供 macOS 27 官方组件套件。
- [Adopting Liquid Glass](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass) 用于原生实现时核对材质与控件采用方式。
- HTML 使用半透明背景、轻量内高光和阴影表现层次，不模拟真实折射。主内容、编辑区和输出区保持实色。深色模式单独调整文字与表面亮度。
- 工具栏与标题栏合并为连续区域，减少横线切割；圆角仅按角色使用，不把所有列表项做成卡片。
- SVG 几何图标用于网页预览，不是 SF Symbols 导出资源；SwiftUI 实现替换为 `terminal`、`bolt`、`magnifyingglass` 等系统符号。
- 保留原生系统控件对降低透明度、增强对比度和系统强调色的支持。设计稿不能替代在 macOS 27 上的最终验收。

## 收尾验证

1. 添加到 10 条命令，检查只显示 ⌘1–9；滚动列表后仍对应原来的前 9 条，搜索后按结果重新编号。
2. 命令管理添加到 10 条以上，滚动到末尾，确认搜索框、添加按钮和底栏留在原位。
3. 编辑名称、命令、分组、目录和开关，点删除再取消，检查所有草稿保留；再次点删除后按 Esc，也应返回草稿。
4. 切换窗口外的自动执行状态预览，检查四种状态下行高一致；悬停和键盘选择时底部详情同步。

## 结果查看与开关验证

- 自动执行有输出的结果可点击查看，浮层内完整文字可选择与复制；查看结果不能触发执行或新增历史。窄窗口仍维持单行 36px。
- 浮层内 Esc 只关闭浮层，保留命令面板与搜索；键盘 Tab 可聚焦结果按钮，Enter 打开浮层。
- 通用页两个开关在悬停时继续保持开启蓝色、关闭灰色，焦点环不替代状态颜色。深浅色分别验证。
