# 优化自动执行命令展示

## Context

命令面板中的自动执行命令（`autoExecute: true`）在执行后的展示有几个体验问题：
- **成功**：命令名和输出混成一行 `命令名：输出`，长输出可读性差
- **失败**：错误文本替代了命令名，看不出是哪个命令出错
- **无区分**：面板和列表中无法区分自动执行命令和普通命令

## 修改文件

| 文件 | 改动 |
|------|------|
| `Sources/App/CommandPaletteView.swift` | `CommandPaletteRow` 四种状态的 UI |
| `Sources/App/Views/CommandsListView.swift` | 命令行添加闪电图标 |

## 方案

### 1. 面板 `.none` 状态 — 添加闪电标识

在命令名前添加 `bolt.fill` 橙色闪电图标（仅 `autoExecute` 命令显示），与列表保持一致视觉语言。

### 2. 命令列表 — 添加闪电标识

在 `CommandsListView` 的拖拽图标旁添加 `bolt.fill` 橙色闪电图标，标识自动执行命令。

### 3. 面板执行结果 — 单行优化

- **`.loading`**：ProgressView + 灰色命令名 + "执行中..." 提示文字
- **`.success`**：绿色 `checkmark.circle.fill` + 命令名（保留搜索高亮）+ 输出文本（caption + secondary 色 + 等宽字体，不换行）
- **`.failure`**：橙色 `exclamationmark.triangle.fill` + 命令名（保留搜索高亮）+ 红色错误信息（caption，不换行）

图标参考 HistoryView 中的 `checkmark.circle.fill` / `xmark.circle.fill` 模式，输出字体参考 HistoryView 的 `.monospaced` 用法。

## 实现顺序

1. 面板 `.none` 状态闪电标识（~6 行）
2. 命令列表闪电标识（~8 行）
3. 面板执行结果单行优化（~30 行替换）

## 验证

1. 构建项目确保无编译错误
2. 手动测试：创建 autoExecute 命令，打开面板观察三种状态展示
3. 验证 CommandsListView 中闪电图标正确显示
4. 验证非 autoExecute 命令不受影响
