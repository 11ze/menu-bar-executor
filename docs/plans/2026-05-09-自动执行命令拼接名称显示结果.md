# 自动执行命令：拼接名称显示结果

## Context

当前自动执行命令成功后，命令面板中会用执行输出**替换**命令名称显示。用户希望改为**拼接**格式，即 `命令名称：执行结果`，这样既能看到命令名称，又能看到结果。

**示例**：命令名称为 `current env`，执行结果为 `production`，显示为 `current env：production`。

## 修改方案

### 修改文件

[CommandPaletteView.swift:298-303](Sources/App/CommandPaletteView.swift#L298-L303) — `.success` 分支的显示逻辑

**当前代码**：
```swift
case .success(let output):
    let displayText = output.isEmpty ? command.name : output
    HighlightedText(text: displayText, search: searchText)
        .font(.body)
        .foregroundColor(.primary)
        .lineLimit(2)
```

**修改为**：
```swift
case .success(let output):
    let displayText = output.isEmpty ? command.name : "\(command.name)：\(output)"
    HighlightedText(text: displayText, search: searchText)
        .font(.body)
        .foregroundColor(.primary)
        .lineLimit(2)
```

仅修改一行：将 `output` 改为 `"\(command.name)：\(output)"`。

## 验证

1. 构建项目确认无编译错误
2. 创建一个 autoExecute 命令，名称为 `current env`，命令为 `echo production`
3. 打开命令面板，确认显示为 `current env：production`
4. 测试 output 为空时仍显示命令名称
