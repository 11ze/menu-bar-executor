# 命令自动执行字段 autoExecute

## Context

用户希望为命令添加一个 `autoExecute` 字段，开启后打开命令面板时自动执行该命令，并将执行结果替换命令名称显示。命令仍可手动点击执行。

## 需求确认

- 字段非必填，默认 `false`
- 打开面板时先显示面板，再异步执行命令替换名称
- 替换名称后命令仍可点击执行（不关闭面板，走正常的 execute 流程）

## 修改文件

### 1. Command.swift — 新增字段

- 新增 `var autoExecute: Bool`
- `CodingKeys` 添加 `case autoExecute`
- 便利初始化器添加 `autoExecute: Bool = false`
- `init(from decoder:)` 中 `decodeIfPresent` + `?? false` 保持向后兼容

### 2. CommandPaletteView.swift — 核心改动

**PaletteCoordinator 新增：**

```swift
enum AutoExecuteState {
    case loading
    case success(String)
    case failure(String)
}

@Published var autoExecuteResults: [UUID: AutoExecuteState] = [:]
```

**新增 `executeAutoCommands()` 方法：**
- 从 `filteredCommands` 中筛选 `autoExecute == true` 的命令
- 对每个命令设置 `.loading` 状态，调用 `CommandExecutor.shared.execute`
- completion 回调中更新为 `.success(output)` 或 `.failure(error)`
- completion 已在主线程（CommandExecutor 保证），直接更新 `@Published` 安全

**修改 `reset()`：**
- 添加 `autoExecuteResults.removeAll()`

**修改 `onAppear` 触发顺序：**
- `refreshCommands()` → `reset()` → 延迟后 `executeAutoCommands()`
- 延迟确保面板先渲染出来，再开始执行

**修改 `CommandPaletteRow`：**
- 新增参数 `autoExecuteState: AutoExecuteState?`
- 显示逻辑：
  - `nil` → 原始命令名称（HighlightedText）
  - `.loading` → ProgressView + 命令名称灰色
  - `.success(output)` → 用 output 替换显示（HighlightedText），output 为空时回退到名称
  - `.failure(error)` → 警告图标 + 错误文本红色

**搜索过滤不改** — 仍按 `command.name` 过滤，执行结果是动态的不适合做搜索键。

### 3. CommandEditorView.swift — 编辑 UI

- 新增 `@State private var autoExecute: Bool`，从 `command?.autoExecute ?? false` 初始化
- "显示设置" Section 中添加 `Toggle("打开面板时自动执行", isOn: $autoExecute)`
- `saveCommand()` 中传入 `autoExecute` 参数

## 不需要修改的文件

- `CommandExecutor.swift` — 通用执行器，无需改动
- `CommandsManager.swift` — autoExecute 走直接 `CommandExecutor` 调用，不走 `CommandsManager.execute()`（避免每次打开面板都写历史和弹通知）
- `CommandsListView.swift` — 仅 CRUD，无需感知

## 验证方式

1. 构建：`xcodebuild -project menu-bar-executor.xcodeproj -scheme MenuBarExecutor build`
2. 在设置中创建一个 autoExecute=true 的命令（如 `echo "hello"` 或 `date`）
3. 打开命令面板，观察：先看到命令名称 → 转为 loading → 显示执行结果
4. 点击该行，验证仍可正常执行
5. 退出重新打开面板，验证结果刷新
