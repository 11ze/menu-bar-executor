# 修复：命令面板自动执行命令只在首次打开时生效

## Context

命令面板中 `autoExecute == true` 的命令只在第一次打开面板时自动执行，后续打开面板不再触发。用户正常使用全局快捷键或点击菜单栏图标打开面板时复现。

## Root Cause

**SwiftUI `.onAppear` 在 NSPanel 的 show/hide 循环中不会重复触发。**

`executeAutoCommands()` 的唯一调用点在 [CommandPaletteView.swift:249-251](Sources/App/CommandPaletteView.swift#L249-L251) 的 `.onAppear` 回调中：

```swift
.onAppear {
    coordinator.refreshCommands()
    coordinator.reset()
    DispatchQueue.main.asyncAfter(deadline: .now() + PaletteConfig.focusDelay) {
        isSearchFocused = true
    }
    DispatchQueue.main.asyncAfter(deadline: .now() + 0.15) {
        coordinator.executeAutoCommands()  // ← 唯一触发点
    }
}
```

问题链：

1. `NSHostingView` 在 init 时创建一次并添加到 `PaletteContainerView`（[CommandPaletteWindowController.swift:68-75](Sources/App/CommandPaletteWindowController.swift#L68-L75)），之后从未移除
2. `hide()` 调用 `panel.orderOut(nil)`，`show()` 调用 `panel.makeKeyAndOrderFront(nil)` — 这只是窗口可见性切换，不是视图层级变化
3. SwiftUI 认为 view 从未离开视图层级，`.onAppear` 只在首次 mount 时触发一次
4. 后续 show/hide 循环中 `.onAppear` 不再触发 → `executeAutoCommands()` 不再被调用

**注意：** `isSearchFocused` 的设置也在 `.onAppear` 里，但因为面板每次 show 时 `reset()` 会清空 `searchText`，SwiftUI 会在 TextField 内容变化时重新评估 focus 状态，所以搜索框聚焦看起来正常。而 `executeAutoCommands()` 依赖的是延迟调用，没有类似的"副作用"驱动重新执行。

## Fix

将 `executeAutoCommands()` 的触发从 `.onAppear` 移到 `CommandPaletteWindowController.show()` 中，确保每次打开面板都会执行。

### 修改文件

#### 1. [CommandPaletteWindowController.swift](Sources/App/CommandPaletteWindowController.swift) — 在 `show()` 方法中触发自动执行

在 `show()` 方法的 `panel.makeKeyAndOrderFront(nil)` 之后，添加延迟调用 `executeAutoCommands()`：

```swift
// 现有代码
panel.makeKeyAndOrderFront(nil)
setupEventMonitor()

// 新增：延迟执行自动命令
DispatchQueue.main.asyncAfter(deadline: .now() + 0.15) {
    PaletteCoordinator.shared.executeAutoCommands()
}
```

放在 `makeKeyAndOrderFront` 之后确保面板已可见，与原 `.onAppear` 中的逻辑保持一致。

#### 2. [CommandPaletteView.swift](Sources/App/CommandPaletteView.swift) — 从 `.onAppear` 中移除自动执行

移除 `.onAppear` 中的 `executeAutoCommands()` 延迟调用：

```swift
// 修改前
.onAppear {
    coordinator.refreshCommands()
    coordinator.reset()
    DispatchQueue.main.asyncAfter(deadline: .now() + PaletteConfig.focusDelay) {
        isSearchFocused = true
    }
    DispatchQueue.main.asyncAfter(deadline: .now() + 0.15) {
        coordinator.executeAutoCommands()
    }
}

// 修改后
.onAppear {
    coordinator.refreshCommands()
    coordinator.reset()
    DispatchQueue.main.asyncAfter(deadline: .now() + PaletteConfig.focusDelay) {
        isSearchFocused = true
    }
}
```

**保留** `.onAppear` 中的 `refreshCommands()` 和 `reset()`，因为它们在首次 mount 时仍然需要。也保留 `isSearchFocused` 的设置作为首次聚焦的保障。

### 不需要修改的部分

- `PaletteCoordinator.reset()` — 现有逻辑正确，每次 show 都会清空 `autoExecuteResults`
- `executeAutoCommands()` 方法本身 — 逻辑正确，无需修改
- `.onDisappear` — 保持不变

5. 重复 3-4 次验证稳定性
6. 测试搜索框聚焦在每次打开时是否正常（不受此修改影响）
