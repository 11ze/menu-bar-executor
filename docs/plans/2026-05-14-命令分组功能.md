# 命令分组功能

## Context

用户有 24 条命令，通过 5 个假命令（`echo -----`，`notification: false`，name 有大量前导空格）模拟分类标题，分为 Status、Claude Code、Personal Code、Work Code、Finder 五组。需要原生的分组支持，提供更好的设置和查看体验。

**方案选择**：给 Command 新增 `group: String?` 字段（而非分隔符类型），因为搜索时分组信息不会丢失，数据模型更干净。

---

## 实现步骤

### 1. 数据模型 — Command 新增 group 字段

**文件**: `Sources/App/Command.swift`

- 新增 `var group: String?`（在 `autoExecute` 之后）
- CodingKeys 新增 `group`
- 便捷 init 新增 `group: String? = nil` 参数
- `init(from decoder:)` 新增 `group = try container.decodeIfPresent(String.self, forKey: .group)` — 缺失时为 nil，向后兼容

### 2. 数据模型 — AppSettings 新增 groupOrder 字段

**文件**: `Sources/App/AppSettings.swift`

- 新增 `var groupOrder: [String]?`（在 `skippedVersion` 之后）
- CodingKeys 新增 `groupOrder`
- `init(from decoder:)` 新增 `groupOrder = try container.decodeIfPresent([String].self, forKey: .groupOrder)`
- `encode(to:)` 新增 `try container.encodeIfPresent(groupOrder, forKey: .groupOrder)`

### 3. 假命令自动迁移

**文件**: `Sources/App/AppSettings.swift`（AppSettingsManager 内）

新增私有方法 `migrateFakeGroupCommands() -> Bool`：
- 遍历 commands，检测假命令模式：`notification == false` + command 以 `echo` 开头 + echo 后全是分隔符字符（`- = # *`）+ name trim 后非空且 < 30 字符
- 假命令：提取 trim 后的 name 作为 currentGroup，标记该条目待删除
- 非假命令：如果 currentGroup 非空且自身 group 为 nil，赋值 currentGroup
- 从后向前删除假命令
- 迁移成功后，提取所有组名写入 `groupOrder`

调用位置：`load()` 中 `fixDuplicateCommandIds()` 之前，合并 save 判断：
```swift
let migrated = migrateFakeGroupCommands()
let fixedIds = fixDuplicateCommandIds()
if migrated || fixedIds { save() }
```

### 4. CommandsManager — 分组排序和搜索适配

**文件**: `Sources/App/CommandsManager.swift`

- `filteredCommands(by:)` 增加对 group 的搜索匹配：
  ```swift
  || (cmd.group?.localizedCaseInsensitiveContains(searchText) ?? false)
  ```
- 新增 `sortedGroupNames(from:) -> [String?]` 方法：
  - 有 `groupOrder` 时按其顺序排，未指定的组按首次出现追加，nil 组排最后
  - 无 `groupOrder` 时按 commands 数组中首次出现顺序

### 5. 命令面板 — PaletteItem 中间层

**文件**: `Sources/App/CommandPaletteView.swift`

新增 `PaletteItem` 枚举：
```swift
enum PaletteItem: Identifiable, Equatable {
    case groupHeader(String)
    case command(Command, displayIndex: Int)
    // id: header 用 "header-\(name)"，command 用 "cmd-\(uuid)"
}
```

### 6. PaletteCoordinator 适配

**文件**: `Sources/App/CommandPaletteView.swift`

核心变更：`filteredCommands: [Command]` → `paletteItems: [PaletteItem]`

- 新增 `buildPaletteItems(from:) -> [PaletteItem]`：
  - 按 sortedGroupNames 分组，有名字的组插入 `.groupHeader`，然后是 `.command(cmd, displayIndex: N)`
  - displayIndex 是命令在所有命令中的绝对编号（1-based）
- `updateFilteredCommands()` → `updatePaletteItems()`：过滤命令后调用 buildPaletteItems
- `moveUp()/moveDown()`：跳过 `.groupHeader` 项
- `executeSelected()`：从 `paletteItems[selectedIndex]` 取 command
- `executeAutoCommands()`：遍历 paletteItems 中的 `.command` 项
- 新增 `firstVisibleCommandIndex` 属性，追踪第一个可见的 command 项的 displayIndex

### 7. 命令面板 UI — 分组渲染

**文件**: `Sources/App/CommandPaletteView.swift`

- ForEach 改为遍历 `coordinator.paletteItems`
- `.groupHeader` → `GroupHeaderRow`（新组件：小字标题，半透明背景）
- `.command` → 现有 `CommandPaletteRow`（displayIndex 改为相对值：`absoluteDisplayIndex - firstVisibleCommandDisplayIndex + 1`）
- `.groupHeader` 行不注册 RowPosition（不参与 firstVisibleIndex 计算）
- `onChange(of: coordinator.selectedIndex)` 滚动逻辑改为用 paletteItem.id

### 8. Cmd+N 快捷键适配

**文件**: `Sources/App/CommandPaletteWindowController.swift`

PaletteContainerView.performKeyEquivalent 中 Cmd+N 逻辑：
```swift
// 从 firstVisibleIndex 开始，找第 N 个 .command 类型的 paletteItem
let visibleCommands = coordinator.paletteItems.enumerated()
    .filter { $0.offset >= coordinator.firstVisibleIndex && $0.element.isCommand }
let target = visibleCommands.dropFirst(num - 1).first
if let target, let cmd = target.element.command {
    coordinator.execute(cmd)
}
```

### 9. 命令编辑器 — 新增组名字段

**文件**: `Sources/App/Views/CommandEditorView.swift`

- 新增 `@State private var group: String`
- init 中从 `command?.group ?? ""` 初始化
- "基本信息" section 中 workDirectory 之后新增 `TextField("分组（可选）", text: $group)`
- saveCommand() 中传入 `group: group.isEmpty ? nil : group`

### 10. 命令列表 — 显示组名

**文件**: `Sources/App/Views/CommandsListView.swift`

- 列表行中命令文本下方，显示组名小标签（蓝色背景圆角标签，类似 tag）
- 搜索过滤逻辑也适配 group 字段（已通过 CommandsManager.filteredCommands 覆盖）

### 11. 测试

**文件**: `Tests/CommandTests.swift`

- testDecoding_MissingGroup：旧 JSON 无 group → nil
- testDecoding_WithGroup：有 group → 正确解码
- testEncoding_GroupRoundTrip：编解码 round trip
- testEquatable_DifferentGroup：group 不同 → 不相等

**文件**: `Tests/AppSettingsTests.swift`

- testDecoding_MissingGroupOrder：旧 JSON → nil
- testMigration_FakeCommands：构造假命令 JSON → 验证迁移后 group 赋值正确、假命令被删除
- testMigration_NoFakeCommands：无假命令不触发迁移
- testMigration_GroupOrder：迁移后 groupOrder 正确设置
